# 2026-09-15 — One-shot demo settlement

Spark: Adapters and humans still had to POST create → fund → submit → release one action at a time to see a full settlement. A contest-valid money-rail slice needs one request that runs the same fee engine end-to-end without inventing a second formula, a server ledger, or real money.

Changed: `POST /api/v0/simulate` walks create → fund → submit → release|dispute through `api/_lib/settlement-transition.js`. Create assigns a real `as_…` id. Response is `{ ok, mode:"demo", money:false, steps, job, payer_credits, receipt }`. Homepage `/` has a small “Run a full demo settlement” control (plus a dispute walk) that POSTs safe defaults, shows the fee/payout cut, stores the receipt in `liberty.agent-settlement.receipts.v0`, and updates local credits/jobs. Docs stay in sync. Still demo / `money: false`. No persistence, Stripe, or claimed volume.
