# 2026-09-15 — Dry-check validate for transition bodies

Spark: Agent builders needed a way to dry-check a Settlement transition body against the live rules and JSON Schema without committing an action, minting a job, or pretending Liberty moves money.

Changed: `POST /api/v0/validate` accepts the same request shape as quote/transition, runs the shared `settlement-transition` engine (dry-run), and returns `{ ok: true }` or structured field errors. Schema errors are 400 with `kind: schema`; state errors are 409 with `kind: state`. It never applies fund/submit/release/dispute, never mints an `as_…` id, and does not persist. Hobby stays at 12 functions via rewrite to `/api/v0/quote?validate=1`. Listed in tools, OpenAPI, quickstart related, What's-new, and `/#integrate`. Still demo / `money: false`.
